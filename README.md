# Gugarythm

Unity 6 LTS 的 2D 音遊專案。此儲存庫目前只準備好 Git 與 Unity 忽略規則；待 Unity Editor 安裝後，會以 Unity Hub 建立正式專案檔案。

現有的網頁版原型位於上層工作區，與此 Unity 專案分離。

## 目前可試玩的基礎場景

開啟 `Assets/Scenes/RhythmPrototype.unity` 後按 Play。這個直向原型含四條觸控軌道、示範譜面、Perfect／Great／Miss 判定、分數與連擊 HUD；先按「開始試玩」，再點擊螢幕下方四個 TAP 區域。

正式美術、封面、音符與音樂的交付規格見 `Assets/Docs/Asset-Handoff.md`。
