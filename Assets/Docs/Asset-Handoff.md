# Gugarythm asset handoff

目前原型用程式繪製，不會把參考截圖或影片直接打包進遊戲。正式素材可依下列位置交付。

| 類型 | 放置位置 | 建議規格 | 用途 |
|---|---|---|---|
| 選曲／遊玩背景 | `Assets/Art/Backgrounds/` | PNG、直向 1080×1920 | 舞台背景與漂浮視窗 |
| 曲繪封面 | `Assets/Art/Jackets/` | PNG、正方形 1024×1024 | 選曲頁、遊玩中背景卡片 |
| Tap 音符 | `Assets/Art/Notes/` | 透明 PNG、約 512×128 | 目前的青／綠／黃／粉圓角長條 |
| Flick 音符 | `Assets/Art/Notes/` | 透明 PNG、約 512×256 | 上箭頭與長條的組合 |
| Hold 頭／身／尾 | `Assets/Art/Notes/` | 透明 PNG、可垂直平鋪 | 長按音符 |
| 音樂 | `Assets/Audio/Music/` | WAV 或 OGG、48 kHz | 遊玩時間軸 |
| 打擊音 | `Assets/Audio/Sfx/` | WAV、短音訊 | Perfect／Great 回饋 |

參考風格：深藍與紫色霓虹背景、青綠黃粉的高對比 note、紫粉判定線與等化器。正式曲繪需具有可用於遊戲的授權。
